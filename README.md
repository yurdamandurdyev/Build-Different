# Sainttraining

Русскоязычный фитнес MVP: адаптивная главная, фильтр программ, тренировочные планы с сохранением в localStorage, рецепты, справочник техники и калькулятор КБЖУ (Миффлин — Сан Жеор).

## Запуск
Node.js 22.12+ или 24 LTS.

```sh
npm ci
npm run dev
```

## Проверки и сборка
```sh
npm test
npm run build
npm run preview
```

Статический результат находится в `dist`. Его можно разместить на Netlify, Vercel или GitHub Pages. Публикация исходников в GitHub сама по себе не публикует сайт.

## Структура
- `src/main.js`: интерфейс и интерактивность.
- `src/style.css`: адаптивное оформление, режим уменьшенной анимации.
- `src/data.js`: редактируемые программы, рецепты и советы.
- `src/nutrition.js`: расчёт калорий и макронутриентов.

## Границы MVP
Нет регистрации, серверной базы, медицинской персонализации и платёжной системы. Сохранённая программа доступна только в текущем браузере. КБЖУ и рекомендации ориентировочные, изображения рецептов иллюстративные. Все иллюстрации созданы для MVP и хранятся локально; используется локальный шрифт Anton (SIL OFL, лицензия в `public/fonts/OFL-Anton.txt`) и системные шрифты. Внешние сервисы для отображения не требуются. До публичного запуска рекомендуется редакторская проверка контента специалистом.

Оригинальная реализация Sainttraining: код, шрифты и графические материалы AW-2025-Portfolio не скопированы.

## Открыть без установки
Скачайте `Sainttraining.html` и откройте двойным щелчком в современном браузере. Файл содержит стили, JavaScript и все иллюстрации; интернет и сервер не нужны. Анимации, калькулятор, фильтры и диалоги работают. Сохранение программы зависит от разрешения браузера на localStorage для локальных файлов.

После изменения исходников обновите файл командой `npm run export:html`.

## Motion edition
Новая композиция по видеореференсу: интерактивное поле линий на Canvas, широкоформатная типографика, вступительная заставка, масштабирование MOVE YOUR WAY при прокрутке, графические постеры и переключатель шалфейной/бумажной палитры. Поддерживается prefers-reduced-motion. Анимации и шрифт включены в автономный HTML.

### Пространственная галерея
Блок MOVE YOUR WAY раскрывается в сцену с перспективой. Обычная прокрутка проводит через шесть интерактивных карточек программ и рецептов, затем возвращает к странице. Прокрутка назад воспроизводит переход в обратном направлении; ссылка «К программам» позволяет пропустить сцену. При `prefers-reduced-motion` карточки показаны статической сеткой.
