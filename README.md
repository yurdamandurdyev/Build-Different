# Sainttraining

Русскоязычный фитнес MVP: адаптивная главная, фильтр программ, тренировочные планы с сохранением в localStorage, рецепты, справочник техники и калькулятор КБЖУ (Миффлин — Сан Жеор).

## Запуск
Node.js 22.12+ или 24 LTS.

```sh
npm ci
npm run dev
```

## Проверки и сборка
```sh
npm test
npm run build
npm run preview
```

Статический результат находится в `dist`. Его можно разместить на Netlify, Vercel или GitHub Pages. Публикация исходников в GitHub сама по себе не публикует сайт.

## Структура
- `src/main.js`: интерфейс и интерактивность.
- `src/style.css`: адаптивное оформление, режим уменьшенной анимации.
- `src/data.js`: редактируемые программы, рецепты и советы.
- `src/nutrition.js`: расчёт калорий и макронутриентов.

## Границы MVP
Нет регистрации, серверной базы, медицинской персонализации и платёжной системы. Сохранённая программа доступна только в текущем браузере. КБЖУ и рекомендации ориентировочные, фото рецептов иллюстративные. Изображения загружаются с Unsplash, шрифты — из Google Fonts; предусмотрены системные шрифты при отсутствии сети. До публичного коммерческого запуска следует проверить права на выбранные изображения и провести редакторскую проверку контента специалистом.

Оригинальная реализация Sainttraining: код, шрифты и графические материалы AW-2025-Portfolio не скопированы.
